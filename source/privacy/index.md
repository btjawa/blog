[**btjawa's Blog**](https://blog.btjawa.dev)（以下简称本站）非常注重您的个人信息与隐私保护。本页介绍本站所采用之各项隐私政策。

1. 您在访问与使用本站时，包括但不限于以下类型的信息可能会被本站收集：
  - 您访问本站时使用的 User Agents 与 IP 地址等
  - 您的设备基本信息
  - 您的网站偏好
  - 您主动发送的其他相关信息

2. 您在本站评论时，您同意来自 [GitHub](https://github.com) 的 [隐私协议](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement) 与 [服务条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)，同时包括但不限于以下类型的信息可能会被本站与第三方服务收集：
  - 您的 [GitHub](https://github.com) 账号基本信息
  - 您在评论时使用的 User Agents 与 IP 地址等
  - 您在评论时使用的设备之基本信息
  - 您在评论时主动发送的其他相关信息

3. 本站使用 Local storage 存储您的网站偏好，包括但不限于以下的偏好可能会被本站收集：
  - 是否显示浏览器原生右键菜单
  - 是否启用暗色模式
  - 其他网站偏好

4. 本站不会主动将您的个人信息泄露给第三方，除非处于以下情形：
  - 保护本站合法权利时
  - 得到您本人的许可时
  - 处于紧急情况，保护个人安全时
  - 需要遵从相关法律法规时
  - 其他符合相关法律法规规定的情形时

本站保留在任何时间修订、修改或变更本页政策的权力。本页元数据之 “更新日期” 的变化表示本页声明已被更新或编辑，更新或编辑的版本在发布后立即取代先前任何版本。
